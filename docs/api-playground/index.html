Tài Liệu Toàn Diện TravelGO Web API (REST & AI)

        

          Dưới đây là đặc tả kỹ thuật và mã lệnh cURL sẵn sàng thực thi cho các endpoint cốt lõi của TravelGO.
        


        
        

          
          

            

              POST
              /api/v1/plan-trip
              — Sinh lịch trình tự động bằng AI
            

            
curl -X POST "http://localhost:8080/plan-trip" \
  -H "Content-Type: application/json" \
  -d '{
    "destination": "Ninh Bình",
    "numDays": 3,
    "numPeople": 2,
    "budgetVnd": 4000000,
    "preferences": ["nghỉ dưỡng", "ẩm thực", "check-in & chill"]
  }'

          


          
          

            

              POST
              /api/v1/chat
              — Trợ lý tư vấn đàm thoại đa lượt
            

            
curl -X POST "http://localhost:8080/chat" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "Gợi ý 3 món ăn đặc sản không thể bỏ qua ở Ninh Bình?"
  }'

          


          
          

            

              GET
              /api/v1/destinations
              — Danh mục điểm đến và toạ độ GPS
            

            
curl -X GET "http://localhost:8080/destinations?region=Trung"

          


          
          

            

              GET / POST
              /api/v1/reviews & /reviews/reply
              — Đánh giá và trả lời review cộng đồng
            

            
# Lấy danh sách đánh giá
curl -X GET "http://localhost:8080/reviews"

# Gửi phản hồi vào một đánh giá
curl -X POST "http://localhost:8080/reviews/reply" \
  -H "Content-Type: application/json" \
  -d '{
    "reviewId": "rev-001",
    "userName": "Thành viên TravelGO",
    "comment": "Chuyến đi này tuyệt thật, cảm ơn bạn đã chia sẻ!"
  }'

          


          
          

            

              POST
              /api/v1/auth/login
              — Xác thực JWT & Tải hồ sơ người dùng
            

            
curl -X POST "http://localhost:8080/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
    "persona": "minh_solo"
  }'

Tài Liệu API & Mã Nguồn Mẫu (cURL)

          
Thầy cô và ban giám khảo có thể chạy trực tiếp các lệnh cURL sau từ terminal hoặc Postman để kiểm chứng phản hồi từ máy chủ Local AI.

        


        
        

          

            POST
            /api/v1/plan-trip
            · Tạo lịch trình cá nhân hóa
          

          
curl -X POST "https://knife-considers-cookbook-incomplete.trycloudflare.com/api/v1/plan-trip" \
  -H "Content-Type: application/json" \
  -d '{
    "destinationName": "Ninh Bình",
    "numDays": 3,
    "numPeople": 2,
    "budgetVnd": 4000000,
    "preferences": ["nghỉ dưỡng", "ẩm thực"]
  }'

        


        
        

          

            POST
            /api/v1/chat
            · Trò chuyện với trợ lý du lịch Qwen
          

          
curl -X POST "https://knife-considers-cookbook-incomplete.trycloudflare.com/api/v1/chat" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "Gợi ý 3 món ăn đặc sản không thể bỏ lỡ tại Đà Nẵng?"
  }'

        


        
        

          

            GET
            /health
            · Kiểm tra trạng thái máy chủ AI
          

          
curl -X GET "https://knife-considers-cookbook-incomplete.trycloudflare.com/health"
